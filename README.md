# AI活用クイック診断／Codex本格診断（非公式）

添付されたAI診断UIを参考に、文章・設問・デザインをすべて新規作成した、スマートフォン優先のスタンドアロンWeb診断です。

## 起動

```bash
cd outputs/codex-nurse-skill-check
python3 -m http.server 8765
```

ブラウザで `http://127.0.0.1:8765/` を開きます。ビルドや外部ライブラリは不要です。

## 内容

- Codexをイメージした薄い紺（ペールネイビー）基調のデザイン
- AIコンサルティング見込み客向け「AI活用クイック診断」：約1分、5問、途中に経済産業省・総務省のAI事業者ガイドラインを示すエビデンス画面、導入準備度と最優先テーマ
- 看護師・医療教育者向け「Codex本格診断」：全34ステップ（開始画面を除く）
- 簡易診断結果をPDF保存し、AIコンサルティング相談時のヒアリング資料として利用可能
- AI知識レベル、利用経験ツール、活用領域の確認
- 日本円ベースのキャリア目標、成果物の積み上がりを示す概念図、日本人モデル入りプロフィール
- 「現在」から「これから」への学習目標を示す比較画面
- 複数選択式の設問と回答途中のプロフィール画面
- 最終回答後のパーソナライズ演出と、回答別の無料7日間実践プラン
- 診断結果から完成目標まで、スマートフォンで1画面1枚ずつ進む全11枚の結果デッキ
- 看護師向けのCodex活用、安全、検証、実行・改善に関する設問
- 4段階の結果判定
- 「指示設計」「安全・検証」「実行・改善」「AIマインド」の4軸表示
- 選択内容に応じた「次の一歩」
- 印刷・PDF保存対応
- 回答は送信・保存せず、ブラウザ内のみで処理

## 表示上の境界

- OpenAI公式の認定・資格ではありません。
- 自己評価に基づく学習用の診断で、臨床判断を行うものではありません。
- 患者・職員を特定できる情報を入力しない前提です。
